# SmartChip Presentation Outline

## 1. Project Introduction

SmartChip is an IoT-based mushroom drying system designed to improve the monitoring and management of the mushroom drying process.

## 2. Problem Addressed

Traditional mushroom drying processes may require continuous manual monitoring of temperature, humidity, drying status, and inventory. SmartChip integrates hardware, cloud services, and a web application to centralize these functions.

## 3. Proposed System

The system consists of:

- React-based web application
- Firebase Authentication
- Cloud Firestore
- ESP32 controller
- Temperature and humidity sensors
- Heater and fan
- LCD display
- Physical control buttons

## 4. System Integration

The web application communicates with Cloud Firestore to manage system information and authorized device commands. The ESP32 communicates with the cloud system and controls the physical drying equipment.

## 5. Major Features

- User authentication and access control
- Drying scheduling
- Sensor monitoring
- Drying-run management
- Inventory management
- Notifications
- History and analytics
- Product reservation

## 6. Project Benefits

SmartChip provides a centralized system for monitoring and managing the mushroom drying process while demonstrating the integration of web technologies, cloud services, and IoT hardware.

## 7. Demonstration Flow

The presentation can demonstrate the following sequence:

1. User logs into the SmartChip web application.
2. The user views the dashboard and device status.
3. A drying operation is scheduled or managed.
4. Sensor and device information are displayed.
5. Cloud Firestore coordinates application and device data.
6. The ESP32 controls the physical drying system.
7. The resulting drying status and inventory information are displayed in the application.
